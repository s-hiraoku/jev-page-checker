プライバシーポリシー

「Jev Audit」は、表示中のウェブページの発行元と本文を、利用者が承認したチェックリストで見る Chrome 拡張です。運営者は s-hiraoku / jev-page-checker です。

収集する情報

  • 利用者が設定画面に保存する TypeSafe API キーと承認者名。
  • 対象タブの URL、タイトル、メタ情報、本文、外部リンクのホスト。
  • 結果（判定、理由、使用量、時刻）。

アカウント登録、広告識別子、位置情報、支払い情報は扱いません。

利用目的

収集した情報は、表示中ページを Jev で Audit し、Inspector と Report に結果を出すためだけに使います。ページの遮断、広告、再販売、プロファイリングには使いません。

共有先

利用者が Audit を実行したとき、本文とメタ情報を含む state を TypeSafe AI（https://api.typesafe.ai）へ送ります。送信は利用者が保存した API キーで認証します。キーや本文を、この拡張の開発者サーバーへ送ることはありません。レポートの結果をもとに、公開・送信・遮断を自動では行いません。

TypeSafe 側の取り扱いは TypeSafe の契約とプライバシー方針に従います。

保存場所と期間

API キー、承認記録、直近の履歴は Chrome の storage.local に保存します。拡張を削除するか、利用者が設定を消すまで残ります。ログにキーは出しません。

利用者の選択

チェックリスト全体を承認し、API キーを保存するまで Live の Audit は走りません。Follow tab をオフにすれば、手動だけになります。拡張を削除すると、端末上の保存データは消えます。
