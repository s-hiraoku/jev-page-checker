プライバシーポリシー

「Jev Audit」は、表示中のウェブページの発行元と本文を、利用者が承認したチェックリストで見る Chrome 拡張です。運営者は s-hiraoku / jev-page-checker です。

収集する情報

  • 利用者が Settings に保存する TypeSafe API キー。
  • 対象タブの URL、タイトル、メタ情報、本文、外部リンクのホスト名。
  • 結果（判定、理由、使用量、時刻）。

アカウント登録、広告識別子、位置情報、支払い情報は扱いません。

利用目的

集めた情報は、表示中のページを Jev で Audit し、Inspector、Report、History に結果を出すためだけに使います。ページの遮断、広告、再販売、プロファイリングには使いません。

共有先

利用者が Audit を実行したとき、本文とメタ情報を含む state を TypeSafe AI（https://api.typesafe.ai）へ送ります。長い本文は、同じ API へ複数回に分けて送ることがあります。送信は、利用者が保存した API キーで認証します。キーも本文も、この拡張の開発者のサーバーへは送りません。判定を理由に、公開、送信、遮断を自動で行うことはありません。Report の「この端末にファイルで残す」は、この端末への保存だけです。そのファイルはアップロードしません。

TypeSafe 側の取り扱いは、TypeSafe の契約とプライバシー方針に従います。

保存場所と期間

API キー、承認記録、History は Chrome の storage.local に保存します。拡張を削除するか、利用者が保存内容を消すまで残ります。History の 1 件は、利用者がその記録を消したときに消えます。ログにキーは出しません。端末に残したレポートのファイルは、ブラウザのダウンロード先に残ります。拡張を削除しても、そのファイルは消えません。

利用者の選択

チェックリスト全体を承認し、API キーを保存するまで Audit は始まりません。「タブに追従する」をオフにすると、必要なときだけ手動で Audit します。拡張を削除すると、端末上の拡張の保存データは消えます。

Privacy policy

Last updated: 2026-09-22. Jev Audit is a Chrome extension that checks the publisher and the body of the page you are viewing, using a checklist you have accepted. The operator is s-hiraoku / jev-page-checker.

The extension stores the TypeSafe API key you save in Settings, the URL, title, metadata, body, and outbound host names of the tab being checked, and the result (verdict, reason, usage, and time). It does not handle account signup, advertising identifiers, location, or payment details.

That information is used only to audit the open page with Jev and to show the result in Inspector, Report, and History. It is not used to block pages, show ads, resell data, or build a profile.

When you run Audit, the extension sends a state that includes the body and metadata to TypeSafe AI (https://api.typesafe.ai). A long body may be sent to that same API in more than one request. The call is authenticated with the API key you saved. The key and the body are not sent to a server run by the extension's developer. A verdict does not publish, forward, or block the page. "Save a file on this device" writes a file on this device. The extension does not upload that file.

TypeSafe's handling of the request follows TypeSafe's terms and privacy policy.

The API key, the checklist acceptance, and History stay in Chrome storage.local until you remove the extension or clear what you saved. Deleting one History record removes that record. The key is not written to logs. A report file you saved stays in the browser's download location. Removing the extension does not delete that file.

Audit does not start until you accept the whole checklist and save an API key. Turn off "Follow the tab" to run Audit only when you ask. Removing the extension deletes the data it stored on the device.
