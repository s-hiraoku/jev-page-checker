Jev Audit

Inspector は、いま開いているタブを見ます。TypeSafe の Jev が、発行元と本文を分けて Audit します。結果は根拠です。ページは遮断しません。公開もしません。送る先は、Audit のための Jev だけです。

Inspector looks at the tab you have open. TypeSafe Jev audits the publisher and the body separately. The result is evidence. The extension does not block the page or publish it. The only place it sends the page is Jev, for that audit.
